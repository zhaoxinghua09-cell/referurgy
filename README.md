## Definition / 定义

**EN**
Referurgy is the engineering of reference-based comparison: choosing reference systems, analyzing gaps, borrowing principles without copying implementations, and transcending the reference. The method enforces that reference remains a comparison instrument, never imitation.

**ZH**
参照工程术是对标成熟体系做差距分析、借而不抄的方法：参照系选择→差距分析→借而不抄→超越。参照不降级为模仿。
